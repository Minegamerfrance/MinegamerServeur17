# MNG FUT 1.3.13

Le chargement du modèle expérimental Robben est désactivé par défaut pour
rétablir le lancement normal de FIFA 20. Le lancement ne reçoit plus `-dataPath`
simplement parce qu'un dossier ModData est présent. Une activation explicite
est nécessaire pour les futurs essais de modèles.

Le raccourci Steam local utilisé pour l'essai a retrouvé ses options initiales.
Les autres raccourcis et les options sans rapport avec le modèle sont conservés.
Les sauvegardes et récompenses du pass ne sont pas modifiées.

Tests : lancement direct et Steam, désactivation par défaut, paramètres
supplémentaires conservés, routage des autres FIFA et compilation du lanceur.
Le démarrage visible du jeu après retour arrière reste à confirmer par le joueur.
