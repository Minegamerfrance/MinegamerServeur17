# MNG FUT 1.3.12

FIFA 20 démarre directement avec `-dataPath "ModData\Default"` lorsque les
données du modèle sont présentes. FIFA 17 conserve son lancement Frosty.
Un raccourci Steam déjà configuré pour le même FIFA20.exe peut être utilisé
depuis MNG FUT ; les options de modèle restent enregistrées dans Steam.
Les réglages personnels Steam ne sont pas distribués dans ce paquet.

Le serveur FIFA 20 1.8.87 inclut les fichiers natifs Robben, leur installateur
contrôlé, les effectifs 2052 et Robben icône 86 en prêt de 10 matchs au niveau 22.
L'installateur conserve les fichiers d'origine du jeu et refuse une version
de jeu incompatible. Aucun remplacement automatique d'un dossier de mods
incomplet n'est effectué.

La lecture des options, la route de lancement, les signatures des manifestes
et l'intégrité des paquets ont été testées. Le rendu du modèle Robben en jeu
reste à confirmer ; cette publication ne constitue pas une validation visuelle.
