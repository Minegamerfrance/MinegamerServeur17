# FIFA 20 serveur 1.8.69 — catalogue EAS FC, première étape

Remplace les réponses « FUT Store / FIFAPoints » du catalogue EAS FC
par une liste dédiée et fournit des réponses de niveau pour un premier
test du panier FIFA 20. La connexion FUT et ses soldes ne sont pas modifiés.

**Validation dans le jeu encore nécessaire.** Ce correctif ne fournit pas
encore les articles, les achats ou les cadeaux du catalogue. Aucun ancien
profil EA, niveau ou crédit n’est restauré automatiquement.

Installer la mise à jour depuis MNG FUT en sélectionnant FIFA 20, puis
redémarrer le serveur et le jeu. Ouvrir le panier et contrôler le résultat.

Le paquet repose sur la version propre 1.8.68, avec seulement le nouvel
overlay EAS FC, son intégration, la documentation et le numéro de version.
Il ne contient aucun compte personnel, sauvegarde de club ni journal.
Les autres fichiers de 1.8.68 sont conservés à l’identique.

Vérifications : 7 tests isolés, compilation des sources Python,
intégrité du ZIP, comparaison des fichiers hérités, taille, SHA-256
et signature du manifeste avec la clé MNG existante.
