# MNG FIFA 20 1.8.87

Mise à jour cumulative du serveur 1.8.86 : catalogue et récompenses persistants,
Lewandowski Flashback, carrousel de chargement, modèle natif Robben et récompense
du niveau 22 : Robben icône 86 en prêt pour 10 matchs, non échangeable.

Le niveau 22 est de nouveau récupérable une seule fois s'il avait déjà été
validé avec son ancienne récompense. Les autres récompenses déjà récupérées
et l'XP sont conservés.

Les modèles sont préparés au premier lancement depuis MNG FUT 1.3.12 pour
la version de FIFA 20 correspondant exactement au fichier layout contrôlé.
Les fichiers du jeu sont conservés ; un autre dossier ModData existant n'est
pas écrasé. Un dossier de mods existant doit déjà contenir le modèle Robben
pour permettre son affichage. Le rendu 3D reste à valider dans le jeu.

Le paquet n'inclut ni comptes, ni base de sauvegarde, ni journaux locaux,
ni réglages Steam personnels. Les manifestes de téléchargement sont signés.
