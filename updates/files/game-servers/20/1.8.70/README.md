# FIFA 20 serveur 1.8.70 — écusson SBC Flashback

Tous les SBC avec récompense joueur de rareté Flashback (51) ou choix
Flashback utilisent l’écusson fourni `flashback_badge.png`, sans retouche.
James BABY et PRIME sont concernés dans le catalogue actuel.
Les futurs SBC sont détectés par leur récompense, pas par un nom de joueur.
Les objectifs Flashback ne sont pas transformés en SBC.

Les autres visuels SBC, les récompenses, les joueurs, les crédits,
les conditions et les compteurs de défis restent inchangés.
Une nouvelle référence d’image évite de réutiliser l’ancien cache.

Le chargement du catalogue EAS FC reste bloqué dans le test de la 1.8.69.
Cette version ne prétend pas corriger ce blocage.

Contrôles : 11 tests isolés, test des deux SBC Flashback dans un serveur
temporaire, image servie identique au PNG fourni, tables de sauvegarde
inchangées, intégrité du ZIP, SHA-256 et signature du manifeste.
L’affichage du badge dans le jeu reste à confirmer après redémarrage.
