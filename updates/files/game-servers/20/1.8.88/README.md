# MNG FIFA 20 1.8.88

Seuls le lancement FIFA 20 et le manifeste de version changent par rapport à
1.8.87. Le serveur ne fournit plus `-dataPath` automatiquement quand il trouve
ModData. Le modèle natif Robben reste expérimental et désactivé par défaut.

Robben icône 86 en prêt de 10 matchs au niveau 22, le catalogue, les effectifs,
toutes les autres récompenses et les données de compte sont conservés.
Les fichiers du modèle restent disponibles pour un futur diagnostic contrôlé.

Les paquets et manifestes sont vérifiés et signés. Le lancement visible après
le retour arrière doit être confirmé dans le jeu ; le visage 3D n'est pas validé.
